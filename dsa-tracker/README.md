# One Problem a Day — DSA Master Tracker

A standalone, dark-themed, zero-friction web application designed for students balancing **B.Tech Semester III (Competitive Coding-I)** with long-term **AI/ML Research & Top-Tier Technical Interview** readiness.

---

## 🚀 Quick Start

1. Open `index.html` directly in any web browser (Chrome, Edge, Firefox, Brave, Safari).
   - Full path: `C:\Users\ishu9\Downloads\CODE\track\dsa-tracker\index.html`
   - No `npm install`, no dev server, and no build step required.
2. Bookmark the page in your browser toolbar (`Ctrl + D`) for your daily morning or evening session.

## ⚡ Key Features

1. **One Problem a Day Psychology**:
   - The top hero card automatically spotlights **Today's Mission**.
   - Direct launch links to LeetCode / GeeksforGeeks.
   - Built-in 🔥 **Daily Streak Counter**.
2. **Infinite Question Capability**:
   - Click **`＋ Add Question`** at the top right to add Day 231, 232... up to Day 1,000+.
   - Assign custom links, platforms, difficulty levels, and pattern tags.
3. **Approach & Notes Vault**:
   - Click the 📝 icon on any question to write and save your intuition, time complexity $O(N)$, and edge cases.
4. **Revision Star (★)**:
   - Mark challenging problems for revision before your bi-weekly college tests or interviews.
5. **Data Backup & Restore**:
   - All progress is saved automatically to browser `localStorage`.
   - Use **`💾 Backup & Sync`** to export a `.json` backup file or restore it on another laptop or phone.
